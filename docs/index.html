📖 V6 怎麼使用？
🚀 明日進場
找下一交易日最值得優先觀察的股票。 不是開盤直接買，而是搭配突破價、量能與追價上限判斷。
🟡 準備進場
趨勢已經成形，但突破或成交量尚未完全確認。 適合加入觀察清單等待訊號。
💎 中長期
主要看 MA20、MA60、MA120、MA240、 相對大盤強度與族群趨勢。 與短線進場使用不同的停損/防守位置。
📊 V6 五大核心
1. Trend — 25分
主要看股價是否站上 MA20， 以及 MA5 > MA10 > MA20、 MA20 > MA60。 多頭排列代表短中期趨勢較完整。
2. Breakout — 25分
看股價與20日高點的距離。 越接近突破位置，分數越高； 正式突破後仍需要成交量確認。
3. Volume — 20分
Volume Ratio = 今日成交量 ÷ 20日平均成交量。 1.2x代表量能開始增加； 1.5x以上代表明顯放量； 2x以上代表強力放量。
4. RS — 15分
Relative Strength不是RSI。 V6比較個股最近20/60日報酬與台灣加權指數， 用來找出真正強於大盤的股票。
5. Sector — 15分
同時比較AI Server、PCB、CPO、被動元件、 散熱、半導體等族群。 強勢族群中的強勢個股會得到較高分數。
🌡 RSI 怎麼看？
RSI 50～65
偏多且通常仍屬健康區域。
RSI 65～70
股票偏強，但需要開始注意追價。
RSI 70～75
強勢但偏熱。V6會降低部分明日進場分數。
RSI ≥ 75
V6視為過熱警示，不會因為RSI高而加分。
💰 買入價格怎麼看？
建議買入區
主要利用 MA10、MA20、ATR 找出拉回承接區。 不是要求一定要在這個價格成交。
突破買點
主要以前20日壓力/高點作為Trigger。 最好搭配成交量同步放大。
最高追價
若隔天直接大幅跳空， 即使股票排名很高，也不應無限制追價。
短線停損
綜合近期低點、MA20與ATR。 跌破代表原本短線Setup可能失效。
中長期防守
主要參考MA60、波段低點與ATR， 空間通常比短線停損更大。
📚 五檔怎麼看？
買一～買五
尚未成交、等待買進的委託。 買一是目前最接近成交價的買單。
賣一～賣五
尚未成交、等待賣出的委託。 賣一是目前最接近成交價的賣單。
突破時怎麼觀察？
如果股價突破V6的突破價， 同時成交量增加，而且賣一/賣二的大單持續被成交， 可以作為突破得到更多確認的線索。
⚠️ 注意
五檔是委託資料，掛單可以撤單或改單。 不應只因為委買量大於委賣量就直接買進。
📊 分價怎麼看？
大量成交區
某個價格累積大量成交， 代表市場在該價位交換大量籌碼， 未來可能形成支撐或壓力區。
突破價上方大量成交
如果突破後成交持續集中在突破價上方， 通常比瞬間突破後立刻跌回更健康。
跌回大量成交區下方
如果突破後又跌回主要成交密集區下方， 要注意突破失敗風險。
V6 是規則式技術分析與候選排序工具， 不是未來報酬保證。買入區、突破價、停損與目標價 皆為依歷史價格與波動計算的策略參考。 實際交易仍需考量隔日跳空、流動性、重大消息與個人風險承受度。
